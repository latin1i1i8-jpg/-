# RpgCore v2.1 — 행성 차원 RPG 플러그인 (Paper/Spigot + 베드락 크로스플레이)

**이번 업데이트 3가지**

1. 🎮 **베드락 에디션도 같이 플레이** — Geyser + Floodgate 로 자바/베드락 동시 접속, 영문 명령어 별칭 + 번호 선택 + 이모지 자동 제거
2. 👹 **몬스터 = 바닐라 마인크래프트 몹, 체력/공격력만 변경** — `config.yml` 의 `mob-stats` 에서 몹별로 직접 숫자 지정
3. 🗼 **시련의 탑** — 돌로 쌓은 탑, 한 층에 몬스터 **1마리**, 잡으면 천장이 열리고 사다리로 위층

## ⚠️ 컴파일 미검증 안내

작업 환경 네트워크가 Maven 저장소(repo.papermc.io)를 막고 있어 `mvn package` 를 실행해보지 못했습니다.
대신 전체 소스 25개 파일을 **구문 검사(파서) 통과**시키고, 탑 구조와 스탯 계산은 별도로 시뮬레이션해 검증했습니다.
빌드 에러가 나면 에러 메시지를 그대로 붙여넣어 주세요 — 바로 고쳐드립니다.

> 참고: 이 코드는 **Paper 1.20.4** 기준입니다. 1.21.3 이상에서는 `Attribute.GENERIC_MAX_HEALTH` 가
> `Attribute.MAX_HEALTH` 로 이름이 바뀌었습니다. 상위 버전에서 쓰실 거면 알려주세요 (2줄만 고치면 됩니다).

## 빌드 & 설치 → **`jar-만드는-방법.md` 참고**

가장 쉬운 방법: 이 폴더를 GitHub 에 업로드하면 **Actions 가 jar 를 자동으로 만들어줍니다**

# 🎮 1. 베드락 에디션 같이 하기

## 구조부터 이해하기

마인크래프트는 **자바판과 베드락판이 서로 다른 프로그램**이라, 하나의 코드로 둘 다 만들 수는 없습니다.
같이 플레이하는 방법은 두 가지입니다.

| 방법 | 설명 | 이 플러그인 |
|---|---|---|
| **A. Geyser 크로스플레이** (이번에 적용) | 자바 서버 1개를 띄우고 베드락 유저가 그 서버에 접속. 서버가 프로토콜을 번역해줌 | ✅ **그대로 사용 가능** |
| B. 베드락 애드온 별도 제작 | `.mcaddon`(비헤이비어팩+리소스팩) JSON 프로젝트를 새로 만듦 | ❌ 코드 공유 불가, 완전 별개 프로젝트 |

**A 방식**을 쓰면 자바 유저와 베드락 유저가 **같은 월드, 같은 행성, 같은 탑에서 같이** 플레이합니다.
RPG 데이터(레벨/골드/직업/탑 기록)도 하나로 공유됩니다. 그래서 A 방식으로 맞췄습니다.

## 서버에 설치할 것 (5분)

1. [GeyserMC](https://geysermc.org/download) 에서 **Geyser-Spigot.jar** 다운로드 → `plugins/`
2. 같은 페이지에서 **floodgate-spigot.jar** 다운로드 → `plugins/` (베드락 유저가 자바 계정 없이 접속하게 해줌)
3. 서버 재시작. 방화벽/포트포워딩에서 **UDP 19132** 를 열어주세요 (베드락은 UDP 사용)
4. 베드락 앱 → 서버 추가 → 서버 IP / 포트 19132 로 접속

설치가 끝나면 서버 로그에 이렇게 뜹니다:
```
[RpgCore] Floodgate 감지됨 — 베드락 플레이어 호환 모드 활성화
베드락 에디션 크로스플레이 지원 중 (Geyser/Floodgate 감지)
```

## 플러그인 쪽에서 해둔 베드락 대응

| 문제 | 대응 |
|---|---|
| 휴대폰/콘솔에서 **한글 명령어 입력이 매우 불편**하고, 베드락 명령창은 한글 명령어를 자동완성해주지 않음 | **모든 명령어에 영문 별칭 추가** (`/job` `/info` `/warp` `/map` `/tower` `/top` …) |
| 한글 직업/행성 **이름을 타이핑**해야 하는 문제 | **번호로 선택 가능** — `/setjob 1`, `/warp 2` |
| 베드락 기본 폰트가 🎉 🪐 🗺️ 같은 **이모지를 □ 로 깨뜨림** | 베드락 유저에게만 **이모지/특수기호 자동 제거** (`bedrock.strip-emoji`) |
| 베드락 유저가 명령어를 모름 | 접속 시 **영문 명령어 안내 자동 표시** (`bedrock.welcome-hint`) |
| Floodgate 가 없는 서버에서 오류 | Floodgate API 를 **리플렉션으로 안전 조회** — 없으면 전부 자바로 취급하고 정상 작동 |

### 명령어 대응표

| 한글 | 영문 별칭 | 기능 |
|---|---|---|
| `/직업` | `/job` `/jobs` `/class` | 직업 목록 (번호 표시) |

| `/행성` | `/planet` `/planets` | 행성 목록 (번호 표시) |

> 베드락 애드온(.mcaddon)을 따로 만드는 B 방식도 원하시면 말씀해주세요.
> 다만 그건 자바 플러그인과 코드/데이터를 공유할 수 없어서, 몬스터 스탯·탑·레벨 시스템을
> JSON 으로 처음부터 다시 만드는 별개 작업이 됩니다.

# 👹 2. 몬스터 = 바닐라 몹, 체력·공격력만 변경

커스텀 몹이나 모델을 쓰지 않습니다. **원래 마인크래프트에 있는 좀비·스켈레톤·크리퍼**가 그대로 나오고,
`config.yml` 의 `mob-stats` 로 **체력과 공격력만** 바뀝니다.

```yaml
mob-stats:
  health-cap: 2000.0       # 체력 상한
  damage-cap: 24.0         # 공격력 상한
  health-per-stage: 0.30   # 단계당 체력 +30%p
  damage-per-stage: 0.06   # 단계당 공격력 +6%p
  base:
    ZOMBIE:   { health: 20.0, damage: 3.0 }   # ← 이 숫자만 고치면 됩니다
    SKELETON: { health: 20.0, damage: 4.0 }
```

- `base` 에 적은 값은 **"테라(배수 1.0) 1단계" 기준**이고, 그 상황에서는 배율이 정확히 1.0 입니다.
  즉 `ZOMBIE: health 20 / damage 3` 은 **바닐라 좀비와 완전히 같음**을 뜻하고,
  `40 / 6` 으로 고치면 모든 좀비가 **체력 2배 · 공격력 2배**가 됩니다.
- 여기에 행성 배수(`mult`)와 단계(스폰 지점에서의 거리)가 곱해집니다.

계산식:
```
체력   = base.health * (1 + ln(행성배수) * planet-health-weight) * (1 + (단계-1) * health-per-stage)
공격력 = base.damage * (1 + ln(행성배수) * planet-damage-weight) * (1 + (단계-1) * damage-per-stage)
```

기본값으로 나오는 좀비 스탯 (체력 / 공격력):

| 행성 | 1단계 | 10단계 | 50단계 |
|---|---|---|---|
| 테라 (x1) | 20 / 3.0 | 74 / 4.6 | 314 / 11.8 |
| 이그니스 (x3.5) | 50 / 4.9 | 185 / 7.5 | 786 / 19.2 |
| 종언 (x400) | 164 / 12.0 | 606 / 18.5 | 2000 / 24.0 |

### 🔧 중요: 화살·폭발·물약 피해도 같이 조정됩니다

마인크래프트에서 **크리퍼 폭발 / 블레이즈·가스트 화염구 / 스켈레톤 화살 / 마녀 물약**은
공격력 속성(`GENERIC_ATTACK_DAMAGE`)을 따르지 않습니다. 속성만 바꾸면 이 몹들은 하나도 안 세집니다.

그래서 이 플러그인은 계산된 **공격력 배율을 몹에 태그로 저장해두고**,
그 몹(또는 그 몹이 쏜 투사체)이 플레이어를 때릴 때 실제 피해에 곱해줍니다.
근접 공격은 속성으로 이미 처리되므로 중복 적용되지 않습니다.

# 🗼 3. 시련의 탑

`/시련의탑` (또는 `/tower`) 로 입장합니다.

- 탑은 **돌**로 쌓여 있습니다 (벽 `STONE`, 바닥/천장 `STONE_BRICKS` — config 변경 가능)
- 한 층에 몬스터가 **딱 1마리**만 나옵니다 (탑 안은 자연 스폰 완전 차단)
- 그 1마리를 잡으면 **천장의 돌 뚜껑이 열리고**, 사다리로 위층에 올라갑니다
- 올라갈수록 그 1마리가 강해집니다 (**층 = 단계**)
- `boss-every`(기본 10)층마다 **보스급 1마리** — 체력 2.5배, 이름표에 `[10층 보스]`
- 총 `floors`(기본 50)층. 최상층을 깨면 정복 메시지 + 자동 퇴장
- 죽거나 나가면 그 회차는 초기화(뚜껑 다시 닫힘)되고 **다시 1층부터**. 최고 기록은 저장됩니다 (`/내정보`)

기본값 기준 탑 몬스터 스탯:

| 층 | 종류 | 체력 | 공격력 |
|---|---|---|---|
| 1층 | 일반 (좀비) | 25 | 3.3 |
| 5층 | 일반 (좀비) | 87 | 5.2 |
| 10층 | 보스 (라바저) | 약 1,400 | 24 |
| 30층 이상 | 보스 | 상한(2,000×2.5) | 24 |

```yaml
tower:
  world: "trial_tower"     # 전용 빈 월드 (자동 생성)
  floors: 50
  room-size: 9             # 9x9 방
  mult-per-floor: 0.25     # 층당 강화 폭
  boss-every: 10
  boss-health-mult: 2.5
  reward-mult: 1.5         # 탑 보상은 행성보다 후하게
  protect-blocks: true     # 돌벽 파괴 금지 (층 건너뛰기 방지)
  wall-block: STONE
  mobs: [ZOMBIE, SKELETON, SPIDER, ...]
  boss-mobs: [RAVAGER, EVOKER, ...]
```

## 구현 상 신경 쓴 부분

- **플레이어별 전용 탑**: 탑 월드 안에서 X축 256블록 간격으로 슬롯을 배정해, 여러 명이 동시에 각자 올라가도 서로 방해하지 않습니다
- **층을 미리 다 짓지 않음**: 올라갈 때 다음 층만 미리 지어서(약 850블록/층) 서버 부담을 줄였습니다
- **갇힘 방지**: 그 층 몬스터가 어떤 이유로든 사라졌는데 뚜껑이 닫혀 있으면 1마리를 다시 소환합니다
- **블록 보호**: 돌벽을 파서 층을 건너뛰거나 탑을 부수는 것을 막습니다 (관리자는 예외)
- **로그아웃/사망 처리**: 탑 안에서 나가면 원래 있던 곳으로 돌려보내고 회차를 정리합니다
- **탑 보상은 은퇴 시스템 예외**: 층마다 항상 골드/XP가 들어옵니다 (행성 몹은 기존대로 2회까지)

# 기존 시스템 (그대로 유지)

### 🪐 행성 차원
- config 의 행성들(테라~종언 6개)이 각각 독립 월드로 자동 생성
- 지도는 직접 제작 가능 (월드 이름에 맞춰 맵 폴더를 넣거나, 생성된 월드를 꾸미면 됨)
- `/행성이동` — 레벨 조건 + 골드 비용 (테라 무료 → 종언 Lv.50 + 3천만G)
- 스폰 지점에서 멀어질수록 단계 상승 (40블록당 +1, 최대 99) — `/지도` 로 확인

### 💀 은퇴 시스템 (완화판)
- 같은 몬스터(행성+종류+단계)를 2번 잡은 뒤부터는 처치는 자유지만 보상 0

### 🎓 직업/레벨 (디스코드 봇 공식 그대로)
- 전사/마법사/궁수/도적, 첫 전직 무료 + 변경 30,000G
- `xp_needed = 50 × level^1.4`, 레벨업 루프 500회 상한(서버 정지 버그 방지)
- `/내정보` `/랭킹` `/골드지급`(관리자)
